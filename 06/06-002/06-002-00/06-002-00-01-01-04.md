# 变量 04-05 视频day01 Shell文献

- 系统预定义变量：
    - 常用系统变量：`${HOME}`、`${PWD}`、`${SHELL}`、`${USER}`。
    - `set`：打印当前Shell的所有变量。
- Bash的初始化流程： #gemini #tocheck
    - 登录交互式：
        - 触发场景：SSH远程登录、`su -l USER`。
        - 加载路径：
            1. `/etc/profile` -> `/etc/profile.d/*.sh`（定义系统[^1]级别的环境变量和启动脚本）
            2. `~/.bash_profile`（定义用户[^2]级别的环境变量和启动脚本） -> `~/.bashrc`（定义用户级别的别名和函数） -> `/etc/bashrc`（定义系统级别的别名和函数）
    - 登录非交互式：
        - 触发场景：`ssh USER@HOST "COMMAND"`。
        - 加载路径：同“登录交互式”。
    - 非登录非交互式：
        - 触发场景：执行脚本。
        - 加载路径：`${BASH_ENV}`
- 自定义变量：
    - 局部变量：
        - 作用域：当前Shell进程。
        - 声明并赋值：`VAR_NAME=VALUE`（弱类型：变量默认为字符串类型）
            - 命名规范：
                - 组成：字母、数字、下划线`_`。
                - 不能以数字开头。
            - 命名风格：全小写 + 下划线`_`分隔单词
            - Shell使用空格来分隔命令和参数。
                - => `=`前后不能有空格
                - => 变量值如果包含空格，使用引号括起来。
        - 取值：`${VAR_NAME}`
    - 环境变量：
        - 作用域：当前Shell进程及其所有子进程。
            - 子进程： #gemini
                - 触发场景：外部命令、脚本。
                - 继承：环境变量、环境函数？ #tocheck
                - 无法直接改变父进程状态。
            - 子Shell： #gemini
                - 触发场景：`( COMMAND )`、管道。
                - 继承：所有的变量和函数。
                - 无法直接改变父进程状态。
        - 声明并赋值：`export VAR_NAME=VALUE`
            - 命名风格：全大写 + 下划线`_`分隔单词
    - 只读变量：
        - 声明并赋值：`readonly VAR_NAME=VALUE`
            - 命名风格：全大写 + 下划线`_`分隔单词
        - 不能修改，也不能撤销（通过关闭Shell进程来回收内存）。
    - 撤销一个变量：`unset VAR_NAME`。
- 特殊变量：
    - `$N`：
        - `$0`：*命令行的*脚本路径/脚本名。
        - `$1`：命令行的第1个参数。
        - ……
        - `$9`：命令行的第9个参数。
    - `$#`：命令行的参数个数。
        - 应用：检查脚本的参数个数。
    - `$*`：命令行的所有参数，所有参数作为一个整体。
    - `$@`：命令行的所有参数，一个参数一个个体。
    - `$?`：前一条命令的退出状态：
        - `0`：执行正确。
        - `非0`：执行错误。

[^1]: 所有用户。

[^2]: 个人用户。
