# 函数 11-12 视频day01 Shell文献

- 系统函数：
    - `basename PATH [SUFFIX]`：提取文件名。
        - `PATH`：绝对路径或相对路径。
            - 路径可以不存在。
            - 路径末尾可以有`/`，不影响结果。
        - `SUFFIX`：文件名中需要去除的后缀。
    - `dirname PATH`：提取父目录的路径（末尾不带`/`）。
        - `PATH`：同“`basename`的`PATH`”。
- 自定义函数：
    - Shell是一门解释型语言（逐行解释运行） => 先声明函数，再调用函数
    - 函数名的命名风格：同“本地变量”。 #gemini
    - 在函数内，默认声明本地变量，为了避免污染本地变量，*必须使用`local`声明局部变量*。 #gemini
        - 作用域：当前函数及其调用的子函数。
        - 命名风格：同“本地变量”。
    - 函数≈命令：
        - 调用函数并传参：`FUNC_NAME ARG1 ARG2...`
        - 函数内获取参数：`$1`、`$2`……
        - 获取退出状态码：`echo "$?"`
            - 省略`return EXIT_CODE`，则函数的退出状态码为函数内的最后一条命令的退出状态码。
    - 获取函数的“返回值”： #gemini
        1. 在函数内使用`echo`。
        2. 在调用处使用命令替换，例如`ret="$( FUNC_NAME ARG1 ARG2... )"`。

```shell
FUNC_NAME() {
    COMMANDS
    [return EXIT_CODE]
}
```
