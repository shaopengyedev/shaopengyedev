- [ ] 使用YUM安装需要联网：
    - [ ] `ping www.baidu.com`
- [ ] 安装epel-release[^1]：
    - [ ] `yum -y install epel-release`
- [ ] 最小安装CentOS7 => 需要安装工具：
    - [ ] `yum -y install vim net-tools psmisc nc rsync lrzsz ntp libzstd openssl-static tree iotop git`
- [ ] 停止firewalld服务，并禁用开机自启[^2]：
    - [ ] `systemctl stop firewalld`
    - [ ] `systemctl disable firewalld.service`
- [ ] 创建用户，并修改用户的密码：
    - [ ] `useradd shaopeng`
    - [ ] `passwd shaopeng`
- [ ] 配置`shaopeng`用户具有`root`权限 => 方便加`sudo`执行`root`权限的命令：
    - [ ] `vim /etc/sudoers`（`93gg i`）
        - [ ] `shaopeng        ALL=(ALL)       NOPASSWD:ALL`
- [ ] 在`/opt`目录下创建`module`和`software`目录，并修改所属主和所属组：
    - [ ] `mkdir /opt/module`
    - [ ] `mkdir /opt/software`
    - [ ] `chown shaopeng:shaopeng /opt/module`
    - [ ] `chown shaopeng:shaopeng /opt/software`
- [ ] `shutdown -h now`

---

- `COMMAND | xargs -n 1 COMMAND`：每次只传递一个参数（来源于前一条命令的输出）给后一条命令。

[^1]: Extra Packages for Enterprise Linux：额外的软件包，大多数RPM包在官方repository中是找不到的。

[^2]: 企业开发：关闭单个节点的防火墙，整体对外打开防火墙。
