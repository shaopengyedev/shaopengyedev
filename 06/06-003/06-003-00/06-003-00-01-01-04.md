# Hadoop组成 07-09 视频day01 Hadoop文献

- Hadoop的版本演变：
    - 1.x：Hadoop = HDFS + MapReduce
        - MapReduce：负责计算和资源调度，耦合性较大。
    - 2.x：Hadoop = HDFS + MapReduce + YARN
        - MapReduce：解耦，只负责计算。
        - YARN：只负责资源调度（调度作业和分配资源）。
    - 3.x：在组成上没有变化。
- 分布式：多个节点（大哥+小弟）完成一件事。
- HDFS (Hadoop Distributed File System)：分布式文件系统。
    - NameNode：维护文件的元数据。
        - 上传文件时，会对文件物理切块，块大小默认为128MB，副本数默认为3。
        - 元数据：例如*文件的块列表、块所在的DataNode节点列表*……
    - DataNode：在DataNode节点的本地存储*文件的块*和块的校验和。
    - SecondaryNameNode：备份NameNode的元数据。
- YARN (Yet Another Resource Negotiator)：资源协调者。
    - ResourceManager：管理整个集群的资源。
    - NodeManager：管理一个节点的资源。
    - Client：客户端，提交一个Job。
        - Job：作业/计算任务。
    - ApplicationMaster：负责一个Job的运行。
    - Container：容器，封装资源，运行一个任务。
        - 资源：磁盘、内存、CPU、网络等。
        - 封装资源 => 可插拔，兼容其他框架的计算任务，例如Spark和Flink。
- MapReduce：
    1. Map阶段：并行处理输入数据。
    2. Reduce阶段：汇总Map阶段的结果。
- MapReduce和HDFS、YARN的关系：
    - HDFS：存储MapReduce的输入数据和输出数据。
    - YARN：分配资源运行MapReduce的Job。
